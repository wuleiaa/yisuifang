# 从零开始：买服务器、买域名、把系统跑到网上

> 写给完全没买过服务器的人。每一步都写清楚点哪里、选什么、怎么知道做对了。
> 预计总耗时：**半天**（其中大部分是等页面加载和实名认证）。

---

## 一、先用大白话讲清楚三个东西

### 1. 服务器 = 一台永远开机的电脑

你现在的项目跑在自己电脑上，你一关机，别人就访问不了了。
服务器就是**放在机房里的电脑，24 小时开着**，所以谁都能访问到。

我们要做的事就是"租"一台这样的电脑，按月付钱（不用自己买硬件）。

### 2. 域名 = 好记的地址

服务器真正的地址是一串数字，比如 `47.76.123.45`，这叫 IP。
域名就是给这串数字起个好记的名字，比如 `followup-demo.com`。

有域名的好处：以后换服务器，只要把域名重新指过去，地址不用改。

### 3. 备案 = 大陆服务器的"登记手续"

| 服务器在哪 | 要不要备案 | 多久能用 |
|---|---|---|
| 中国大陆（北京、杭州…） | **要**，7–20 个工作日 | 慢 |
| 中国香港 / 新加坡 | **不用** | 买了就能用 |

我们做演示环境用**香港**，当天就能跑起来。

> 以后要给医院正式用，服务器肯定在国内（数据不能出境），那时候再走备案，而且备案要用医院的主体，不是个人的。

## 二、要花多少钱

| 东西 | 建议 | 价格（大约） |
|---|---|---|
| 云服务器 | 阿里云轻量应用服务器 2核4G，香港 | 60–150 元/月 |
| 域名（可选） | `.com` 或 `.cn` | 首年 30–80 元 |
| HTTPS 证书 | Let's Encrypt | 免费 |
| **合计** | | **先花 100 元左右试一个月** |

建议**先买 1 个月**，跑通了再续年付（年付便宜很多）。

## 三、第一步：注册阿里云账号（约 15 分钟）

1. 浏览器打开 **aliyun.com**
2. 右上角点「免费注册」，用手机号注册（也可以直接用支付宝扫码登录）
3. **实名认证**（必须做，不做买不了任何东西）：
   - 页面右上角头像 → 「实名认证」
   - 选「个人」→ 填身份证号 → 手机验证 → 人脸识别
4. **怎么知道做对了**：右上角头像旁边能看到你的名字，不再提示"未实名"

---

## 四、第二步：买服务器（约 20 分钟）

1. 打开阿里云首页，搜索框输入 **轻量应用服务器**，进入产品页
2. 点「立即购买」，然后按下面选：

   | 选项 | 选什么 | 为什么 |
   |---|---|---|
   | 地域 | **中国香港** | 免备案，当天能用 |
   | 镜像 | **系统镜像 → Ubuntu 22.04** | 我们整套部署都按 Ubuntu 写的 |
   | 套餐 | **2核4G**（预算紧选 2核2G 也行） | 我们实测系统占约 800MB 内存 |
   | 系统盘 | 默认 40–50G | 够用 |
   | 购买时长 | **1 个月** | 先试，跑通再续 |
   | 数量 | 1 台 | |

3. **设置密码**：会让你设 root 密码
   - 点「自定义密码」
   - 设一个**强密码**（大小写字母 + 数字 + 符号，12 位以上）
   - **立刻抄在纸上或存进手机备忘录**——这是服务器的钥匙，丢了只能重置

4. 勾选协议 → 付款

5. **怎么知道做对了**：
   - 进入「控制台」→「轻量应用服务器」
   - 能看到一台实例，状态是**运行中**
   - **把「公网 IP」抄下来**（形如 `47.76.123.45`），后面要用

### ⚠️ 关键一步：开放端口（很多人卡在这）

阿里云轻量服务器默认只开了 22 端口，**80 和 443 要自己加**，否则网站在浏览器里打不开。

1. 在轻量应用服务器控制台，点进你的实例
2. 左侧找「**防火墙**」（有的版本叫「安全」→「防火墙」）
3. 添加两条规则：

   | 应用类型 | 协议 | 端口 | 备注 |
   |---|---|---|---|
   | 自定义 | TCP | 80 | 网页访问 |
   | 自定义 | TCP | 443 | HTTPS |

4. **怎么知道做对了**：防火墙列表里能看到 80 和 443 两条规则

---

## 五、第三步：买域名（可选，约 15 分钟）

不想买域名也可以，直接用 IP 访问。但有了域名后面省事。

1. 阿里云首页搜索 **域名注册**
2. 输入你想用的名字，比如 `followup-demo`，点查询
3. 挑一个没人注册的后缀（`.com` / `.cn` / `.top` 都行），点「加入清单」→ 购买
4. **实名认证**：域名买了之后要单独实名（个人身份证），一般 1–2 小时通过
5. **怎么知道做对了**：「域名控制台」里域名的状态是「实名认证成功」

---

## 六、第四步：把域名指向服务器（约 10 分钟）

这一步叫「解析」，就是告诉互联网：`followup-demo.com` 这个域名，对应的是我那台服务器的 IP。

1. 进「域名控制台」→ 点你刚买的域名 → 找「**解析**」→「添加记录」
2. 填成这样：

   | 字段 | 填什么 |
   |---|---|
   | 记录类型 | **A** |
   | 主机记录 | **@** |
   | 解析线路 | 默认 |
   | 记录值 | **你的服务器公网 IP** |
   | TTL | 默认（10 分钟） |

3. 再添加一条一样的，但「主机记录」填 **www**

4. **怎么知道做对了**：等 5–10 分钟，在自己电脑上打开命令提示符，输入
   ```
   ping followup-demo.com
   ```
   如果显示的 IP 就是你服务器那个 IP，说明成功了。

---

## 七、第五步：连上服务器（约 10 分钟）

Windows 电脑不用装任何软件，自带工具就能连。

1. 按 `Win + R`，输入 `cmd`，回车，打开黑色窗口
2. 输入下面这行（换成你的服务器 IP），回车：
   ```
   ssh root@你的服务器IP
   ```
3. 第一次会问 `Are you sure you want to continue connecting?`，输入 **yes** 回车
4. 输入你买服务器时设的密码（**输入时屏幕上不会显示任何字符，这是正常的**，输完直接回车）

5. **怎么知道做对了**：窗口里的提示符变成类似
   ```
   root@iZbp1xxxxx:~#
   ```
   这就说明你已经"坐到"那台服务器里面了。后面所有命令都在这个窗口里敲。

---

## 八、第六步：部署（半小时，命令我一条条给你）

连上服务器后，依次执行下面几段。**一段一段粘贴，别一次性全贴**。

### 6.1 设置时区（很重要）

```bash
timedatectl set-timezone Asia/Shanghai
date
```

看到输出里有 `+0800` 就对了。**随访的"逾期几天"全依赖这个时间，不能错。**

### 6.2 安装 Docker

```bash
curl -fsSL https://get.docker.com | bash
docker --version
docker compose version
```

两条命令都有版本号输出就对了。

### 6.3 开放防火墙

```bash
ufw allow 22
ufw allow 80
ufw allow 443
ufw enable
ufw status
```

（提示 `Command may disrupt existing ssh connections` 时输入 `y` 回车。）
输出里**不应该有 5432**——数据库端口绝不能对外开放。

### 6.4 把项目传上去

这一步需要项目文件。两种办法：

- **办法一（推荐）**：把项目打包成 zip 发给我，我帮你把命令写好
- **办法二**：你自己把项目文件夹压缩，用阿里云控制台的「文件上传」传到服务器

### 6.5 启动系统

```bash
cd /opt/followup/deploy
cp .env.example .env
```

然后生成 6 个密码（一条一条执行，把输出抄下来）：

```bash
openssl rand -base64 32
```

执行 6 次，分别填到 `.env` 文件里的这 6 个位置：
`DB_SUPERUSER_PASSWORD`、`DB_APP_PASSWORD`、`REDIS_PASSWORD`、
`APP_CRYPTO_DATA_KEY`、`APP_CRYPTO_HASH_PEPPER`、`APP_JWT_SECRET`。

> **注意**：`APP_CRYPTO_DATA_KEY` 和 `APP_CRYPTO_HASH_PEPPER` 是加密患者手机号的钥匙，
> **必须抄在纸上单独保管**。这两个值一旦丢失，已经存进数据库的手机号就再也解不开了。

修改 `.env` 用这个命令（Linux 自带编辑器）：

```bash
nano .env
```
改完按 `Ctrl + O` 回车保存，再按 `Ctrl + X` 退出。

然后启动：

```bash
docker compose up -d
docker compose ps
```

四个容器都显示 `running` 或 `healthy` 就成功了。

### 6.6 验证

```bash
curl -s localhost/health
```

返回 `{"status":"UP"}` 就对了。然后在自己电脑的浏览器里打开：

```
http://你的域名/
http://你的域名/patient/
http://你的域名/admin/
```

三个页面都能打开，说明部署成功。

## 十、新手最容易卡住的五个地方

| 卡在哪 | 原因 | 怎么办 |
|---|---|---|
| 浏览器打不开网站 | 阿里云控制台的**防火墙**没开 80 端口 | 回到第四步最后那段，加 80、443 规则 |
| `ssh` 连不上 | IP 抄错了 / 密码输错 / 防火墙没开 22 | 确认 IP；密码输错重新输；22 是默认开的 |
| 输入密码时屏幕不动 | **这是正常的**，Linux 输密码不显示任何字符 | 照常输完回车 |
| `docker compose up` 报错 | 多半是 `.env` 里有没替换的 `CHANGE_ME` | 执行 `grep CHANGE_ME .env`，输出为空才对 |
| 网站打开是白屏 | 前端文件没放对位置 | 把报错发我，我远程看 |
